# 제품 상세페이지 이미지

각 제품의 스마트스토어 상세페이지 이미지를 아래 규칙으로 업로드하면
해당 제품 상세 페이지에 세로로 순서대로 자동 표시됩니다.

## 파일명 규칙 (제품 slug + 순번)

### 앰플 (Hydro Regene Air Ampoule)
- ampoule-01.jpg, ampoule-02.jpg, ampoule-03.jpg ... (위→아래 순서)

### 스피큘 밤 (Hydro Volume Boosting Spicule Balm)
- balm-01.jpg, balm-02.jpg, balm-03.jpg ...

### 2종 세트 (Signature Duo)
- set-01.jpg, set-02.jpg, set-03.jpg ...

## 참고
- 확장자는 .jpg / .png / .webp 모두 가능 (먼저 .jpg, 없으면 .png, .webp 순으로 자동 탐색)
- 번호는 01부터 시작, 최대 40장까지 자동 인식
- 한 장으로 된 긴 상세컷이면 ampoule-01.jpg 하나만 올려도 됩니다
